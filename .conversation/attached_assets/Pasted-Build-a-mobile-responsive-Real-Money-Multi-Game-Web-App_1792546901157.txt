Build a mobile-responsive Real-Money Multi-Game Web Application using Node.js. The app must use local JSON/Object storage for user accounts and live transactions, with absolutely ZERO external payment gateway APIs. Everything must run on a manual validation system. Strictly ensure there are NO helpline numbers, support text, contact forms, email links, or any customer query features anywhere in the entire application.

1. USER AUTHENTICATION & WALLET SYSTEM:
- Implement a secure User Signup and Login page.
- Upon signup, every new user automatically receives a ₹10 "Bonus Balance" (generated digitally by the system).
- Each user profile must track three independent wallet streams: 'Deposit Balance', 'Winning Balance', and 'Bonus Balance'.

2. MULTI-GAME LOBBY & ENTRY MATH:
- Create a user dashboard displaying a grid of simple HTML5 mini-games (e.g., a Snake game, a Clicker game, and a Tic-Tac-Toe game).
- To play a game, it requires a strict ₹60 Entry Fee. 
- Balance Combination Rule: A user can only use a maximum of 10% Bonus Cash per game match. Therefore, the system must only let them enter if they have at least ₹54 in 'Deposit Balance' and exactly ₹6 in 'Bonus Balance' to combine into the ₹60 fee.
- Simulate 1v1 match logic. When a game ends, the platform takes a 10% platform fee (Rake) from the total ₹120 pool. The winner is awarded ₹108 directly into their 'Winning Balance'.

3. MANUAL TRANSACTIONS (USER PANEL):
- "Add Cash" Page: Display a placeholder text stating "Our UPI ID: YOUR_UPI_ID@HERE" and a placeholder image slot for a payment QR code. Provide text input fields for "Amount to Deposit", "UPI Ref / UTR Number", and an image file upload slot for their transaction screenshot. Submitting this creates a "Pending Deposit" ledger entry. 
- "Withdraw Cash" Page: Allow users to input their destination UPI ID and type an amount to cash out from their 'Winning Balance'. The system must automatically calculate and display a 5% platform processing tax/fee, show the final payout amount, immediately deduct the full requested amount from their balance, and create a "Pending Withdrawal" entry.

4. MANUAL OPERATIONS (ADMIN CONTROL PANEL at '/admin'):
- Build a secure dashboard route at '/admin' hidden from normal players.
- Display cards tracking live statistics: Total Game Rake Collected, Total Withdrawal Taxes Collected, and Number of Active Pending Requests.
- List all "Pending Deposits" showing User ID, UTR Number, and the uploaded screenshot link. Provide an "Approve" button (which adds the points to that user's Deposit Balance) and a "Reject" button.
- List all "Pending Withdrawals" showing the user's target UPI ID and the final payout amount (with the 5% tax already subtracted). Provide a "Mark as Completed" button to archive the request after the admin manually transfers the cash using GPay/PhonePe.
